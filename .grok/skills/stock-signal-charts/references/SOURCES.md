# Sources (consulted 2026-09-10)

- [quantopian/alphalens](https://github.com/quantopian/alphalens) — IC, quantile returns, monthly IC heatmap, turnover. Apache-2.0.
- [HKUDS/Vibe-Trading#1099](https://github.com/HKUDS/Vibe-Trading/pull/1099) — React factor tab: IC bars, 20d mean, quantile equity, IC correlation heatmap.
- [peterajhgraham/real-time-stock-dashboard](https://github.com/peterajhgraham/real-time-stock-dashboard) — overlay indicators + dedicated z-score / Sharpe / drawdown panels.
- [WenyuChiou/moodring](https://github.com/WenyuChiou/moodring) — IC as signal-health, decay → recalibration (do **not** auto-search weights on OOS in this desk).
- [tradingview/lightweight-charts](https://github.com/tradingview/lightweight-charts) — optional candle engine; this stack uses Recharts unless candles are the product.
