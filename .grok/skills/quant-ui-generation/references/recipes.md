# Recipes

## Metric strip

2×3 on mobile, 6-col on lg. Label 11px `text-subtle`. Value `text-lg tabular`.
Sign color only on the number.

## Tab bar

`rounded-xl bg-surface p-1 ring-1 ring-border`. Active: `bg-surface-3 text-fg`.
Icons 14px stroke 1.75.

## Heat cells

`aspect-square` or fixed 10–12px. `rounded-[2px]`. Title attribute = ticker,
date, z. Legend row under the grid.

## Range inputs

Native `input[type=range]` with `accent-accent`, label + tabular value on one
row. Height of the hit area via padding, not a tiny thumb-only target.
